3-COMMAND CONVERSION PIPELINE
================================================================================

1. Activate environment:
   $ source ml_env/bin/activate

2. Convert model (main step - takes 6-8 minutes):
   $ python3 scripts/convert_to_coreml.py
   
   Output: ./models/coreml/RecyclingNet11.mlpackage/

3. (Optional but recommended) Quantize for production:
   $ python3 scripts/quantize_coreml.py
   
   Output: ./models/coreml/RecyclingNet11_int8.mlpackage/
   Size: ~88 MB (vs. 200-350 MB original)

WHAT EACH COMPONENT DOES
================================================================================

DOWNLOADED MODEL (model.safetensors):
  • 354 MB PyTorch weights
  • Contains neural network parameters (354M parameters total)
  • Trained on viola77data/recycling-dataset
  • Already optimized for waste classification

ONNX CONVERSION:
  • Translates PyTorch operations to standardized format
  • Acts as bridge between PyTorch and Core ML
  • All operations verified for compatibility
  • Can be deleted after Core ML generation

CORE ML PACKAGE:
  • Apple's native format for iOS/macOS ML models
  • Optimized for ANE (Apple Neural Engine)
  • Includes metadata, I/O descriptions
  • Ready to embed in Xcode project

QUANTIZATION (int8):
  • Reduces each weight from 4 bytes → 1 byte
  • 75% size reduction (354 MB → 88 MB)
  • <1% accuracy loss (typical)
  • ANE optimization enabled
  • Recommended for production

SWIFT LOADER:
  • Loads Core ML model from app bundle
  • Runs inference on camera frames
  • Converts output logits to probabilities
  • Handles error cases gracefully

TEST SUITE:
  • Verifies model loads correctly
  • Tests inference output validity
  • Measures latency on target device
  • Ensures all 11 classes present

TROUBLESHOOTING QUICK REFERENCE
================================================================================

❌ "ModuleNotFoundError: No module named 'torch'"
   ✅ Activate venv: source ml_env/bin/activate

❌ Script hangs during "Loading model"
   ✅ Normal - takes 5-10 minutes. Be patient. GPU loading is slow.

❌ "opset version not supported by Core ML"
   ✅ Already handled - script uses opset 14 (max for Core ML)

❌ Core ML model too large for app bundle
   ✅ Use quantized int8 version (88 MB instead of 200-350 MB)

❌ Model won't load in Xcode
   ✅ Ensure .mlpackage is added to RecycleMVPKit target

❌ Inference returns NaN
   ✅ Image preprocessing not implemented yet (see TODO in ModelLoader.swift)

❌ Latency >1500ms
   ✅ Check computeUnits = .all in ModelLoader.swift (needs ANE)
